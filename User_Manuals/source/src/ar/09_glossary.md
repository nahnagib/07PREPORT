# مسرد المصطلحات

تظهر المصطلحات بالإنجليزية كما تظهر في اللوحة، ومرتبة أبجديًا.

<!-- sort -->
| المصطلح | المعنى |
|---|---|
| **7Ps** | العناصر السبعة للمزيج التسويقي التي تُنظَّم وفقها اللوحة: المنتج، والسعر، والمكان، والترويج، والأفراد، والعمليات، والدليل المادي. |
| **Actual** | القيمة الفعلية المتحققة في الفترة المختارة. |
| **ASP** | متوسط سعر البيع: قيمة المبيعات ÷ الكمية المبيعة. |
| **B2B / B2C** | مجموعتا عملاء: البيع للشركات (B2B)، والبيع للمستهلكين (B2C). |
| **Behind Target / Watch** | الحالة الكهرمانية: دون الهدف بنسبة 10% أو أقل. |
| **Critical / Off target** | الحالة الحمراء: دون الهدف بأكثر من 10%. |
| **CSV** | ملف جدول بقيم مفصولة بفواصل، يُفتح في Excel. |
| **Customer Group** | شريحة العملاء (مثل B2B وB2C). |
| **Distribution Channel** | قناة التوزيع التي تتم عبرها عملية البيع. |
| **FMT** | هدف الشهر كاملًا (Full-Month Target) للشهر الحالي. |
| **FY / FM Target** | هدف السنة كاملة / هدف الشهر كاملًا. |
| **FYT** | هدف السنة كاملة (Full-Year Target). |
| **K / M** | ألف / مليون (مثلًا LYD 14.1M = 14.1 مليون دينار ليبي). |
| **LFM** | الشهر الكامل السابق (Last Full Month): القيمة الفعلية للشهر الميلادي السابق كاملًا. |
| **LFY** | السنة الكاملة السابقة (Last Full Year): القيمة الفعلية للسنة الميلادية السابقة كاملة. |
| **LMTD** | الشهر نفسه من السنة الماضية حتى اليوم نفسه. |
| **LYD** | الدينار الليبي. |
| **LYTD** | من 1 يناير حتى اليوم نفسه في السنة الماضية. |
| **MTD** | منذ بداية الشهر حتى التاريخ المختار. |
| **On Track / On target / On Pace** | الحالة الخضراء: تحقق الهدف أو تم تجاوزه. |
| **Performance Details** | جدول الملخّص في أسفل معظم التقارير. |
| **Refresh** | التحديث المجدول لبيانات اللوحة من أنظمة الشركة. |
| **Salesperson** | مندوب المبيعات الذي تُنسب إليه عملية البيع. |
| **SKU** | وحدة تعريف المخزون: صنف منتج واحد. |
| **Status badge** | شارة الحالة الملوّنة (أخضر / كهرماني / أحمر / رمادي) على البطاقة. |
| **Target-to-date** | الجزء من الهدف الذي يُفترض تحقيقه حتى التاريخ المختار. |
| **Variance** | الفرق بين رقمين كنسبة مئوية، مثل الفعلي مقابل الهدف أو هذه السنة مقابل السابقة. القيمة الموجبة تعني أعلى. |
| **Volume** | الكمية المبيعة (بالوحدات). |
| **YTD** | منذ بداية السنة (1 يناير) حتى التاريخ المختار. |
<!-- only:full -->
| **Aging** | عمر الفرصة أو عرض السعر المفتوح (0-30 أو 30-60 أو 60-90 أو أكثر من 90 يومًا). |
| **BCG Matrix** | تصنيف المنتجات حسب الكمية والربحية: Stars وCash Cows وStrategic وDogs. |
| **Blocked customer** | عميل محظور في نظام الشركة. |
| **Branch** | الفرع البائع أو فريق المبيعات. |
| **CAC** | تكلفة اكتساب العميل: التكلفة التسويقية لكسب عميل جديد واحد. |
| **Cash Cows** | منتجات ذات كمية مرتفعة وربحية أقل. |
| **Churn Rate** | معدل الفقدان: نسبة عملاء السنة الماضية الذين لم يشتروا هذه السنة. |
| **CPC** | تكلفة النقرة في الإعلانات الرقمية. |
| **Critical Number** | قيمة المبيعات اليومية اللازمة لمواكبة الهدف السنوي. |
| **CRM** | نظام إدارة علاقات العملاء، وتُسجَّل فيه الفرص وعروض الأسعار. |
| **CTR** | نسبة النقر: النقرات ÷ مرات الظهور. |
| **Days of Inventory / DOH** | عدد الأيام التي يكفيها المخزون الحالي بمعدل البيع الحالي. |
| **Dogs** | منتجات ذات كمية منخفضة وربحية أقل. |
| **Drill-down** | النقر على عنصر في الرسم لعرض السجلات التي يقوم عليها. |
| **Fast / Slow Movers** | المنتجات ذات أعلى / أدنى معدل مبيعات يومي. |
| **Forced Closure** | يوم أُغلق فيه فرع بشكل غير متوقع. |
| **GP%** | نسبة إجمالي الربح. |
| **Invoice Class A–D** | فئات قيمة الفواتير: A أكثر من 50 ألفًا، وB من 25 إلى 50 ألفًا، وC من 5 إلى 25 ألفًا، وD أقل من 5 آلاف دينار. |
| **MARCOM** | الاتصالات التسويقية. |
| **Missing Value / Missing Days** | مقدار تقدّم المبيعات (+) أو تأخرها (−) عن الوتيرة المطلوبة، بالدينار أو بالأيام. |
| **Opportunity** | فرصة بيع مسجّلة في CRM. |
| **Overstock** | مخزون يتجاوز حدّ أيام المخزون المعتمد للشركة. |
| **Pareto chart** | رسم بأعمدة مرتبة حسب الحجم مع خط للنسبة التراكمية. |
| **Pipeline** | جميع الفرص وعروض الأسعار المفتوحة. |
| **PIM** | إدارة معلومات المنتجات: هيكل المنتجات (الشركة، الفئة، العلامة، العائلة، المقاس، المنتج). |
| **Quotation** | عرض سعر يُرسل إلى العميل. |
| **Retention Rate** | معدل الاحتفاظ: نسبة عملاء السنة الماضية الذين اشتروا مجددًا هذه السنة. |
| **ROI** | العائد على الاستثمار: الإيرادات ÷ الإنفاق. |
| **Stars** | منتجات ذات كمية مرتفعة وربحية مرتفعة. |
| **Stock-Out Risk** | مخزون يقل عن الحد الأدنى لأيام المخزون المعتمد للشركة. |
| **Strategic** | منتجات ذات كمية منخفضة وربحية مرتفعة. |
| **Win Rate** | نسبة الفوز: عروض الأسعار المكسوبة كنسبة من العروض التي حُسم أمرها. |
| **Working Days** | أيام التقويم ناقص أيام الراحة الأسبوعية (الجمعة) والعطلات الرسمية. |
