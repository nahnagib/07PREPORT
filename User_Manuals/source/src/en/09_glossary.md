# Glossary

<!-- sort -->
| Term | Meaning |
|---|---|
| **7Ps** | The seven parts of the marketing mix used to organise the dashboard: Product, Price, Place, Promotion, People, Process, Physical Evidence. |
| **Actual** | The real figure achieved in the selected period. |
| **ASP** | Average Selling Price: sales value ÷ volume sold. |
| **B2B / B2C** | Business-to-business and business-to-consumer customer groups. |
| **Behind Target / Watch** | Amber status: below target by 10% or less. |
| **Critical / Off target** | Red status: below target by more than 10%. |
| **CSV** | Comma-separated values, a table file that opens in Excel. |
| **Customer Group** | Customer segment (for example B2B, B2C). |
| **Distribution Channel** | The route through which a sale is made. |
| **FMT** | Full-Month Target: the whole current month's target. |
| **FY / FM Target** | Full-Year / Full-Month Target. |
| **FYT** | Full-Year Target. |
| **K / M** | Thousand / million (for example LYD 14.1M = 14.1 million Libyan dinars). |
| **LFM** | Last Full Month: the actual of the previous complete calendar month. |
| **LFY** | Last Full Year: the actual of the previous complete calendar year. |
| **LMTD** | Last-year Month-To-Date: the same month last year, up to the same day. |
| **LYD** | Libyan Dinar. |
| **LYTD** | Last Year-To-Date: 1 January to the same day, last year. |
| **MTD** | Month-To-Date: from the 1st of the month to the selected date. |
| **On Track / On target / On Pace** | Green status: target reached or exceeded. |
| **Performance Details** | The summary table at the bottom of most reports. |
| **Refresh** | The scheduled update of dashboard data from company systems. |
| **Salesperson** | The person credited with a sale. |
| **SKU** | Stock Keeping Unit: a single product item. |
| **Status badge** | The coloured label (green / amber / red / grey) on a card. |
| **Target-to-date** | The part of the target that should have been reached by the selected date. |
| **Variance** | The difference between two figures as a %, for example actual vs target or this year vs last year. Positive means higher. |
| **Volume** | Quantity sold (units). |
| **YTD** | Year-To-Date: from 1 January to the selected date. |
<!-- only:full -->
| **Aging** | How long an opportunity or quotation has been open (0-30, 30-60, 60-90, 90+ days). |
| **BCG Matrix** | Product classification by volume and profit: Stars, Cash Cows, Strategic, Dogs. |
| **Blocked customer** | A customer blocked in the company system. |
| **Branch** | The selling branch or sales team. |
| **CAC** | Customer Acquisition Cost: marketing cost to win one new customer. |
| **Cash Cows** | High-volume, lower-profit products. |
| **Churn Rate** | Share of last year's customers who haven't bought this year. |
| **CPC** | Cost Per Click in digital advertising. |
| **Critical Number** | The daily sales value needed to stay on pace with the annual target. |
| **CRM** | Customer Relationship Management, where opportunities and quotations are recorded. |
| **CTR** | Click-Through Rate: clicks ÷ impressions. |
| **Days of Inventory / DOH** | How many days current stock will last at the current sales rate. |
| **Dogs** | Low-volume, lower-profit products. |
| **Drill-down** | Clicking a chart element to see the records behind it. |
| **Fast / Slow Movers** | Products with the highest / lowest daily sales rate. |
| **Forced Closure** | A day a branch was closed unexpectedly. |
| **GP%** | Gross Profit percentage. |
| **Invoice Class A–D** | Invoice value bands: A > 50K, B 25–50K, C 5–25K, D < 5K LYD. |
| **MARCOM** | Marketing Communications. |
| **Missing Value / Missing Days** | How far sales are ahead of (+) or behind (−) the required pace, in LYD or in days. |
| **Opportunity** | A potential sale recorded in the CRM. |
| **Overstock** | Stock above the company's days-of-inventory limit. |
| **Pareto chart** | Bars sorted by size, with a cumulative % line. |
| **Pipeline** | All open opportunities and quotations. |
| **PIM** | Product Information Management: the product hierarchy (company, category, brand, family, size, product). |
| **Quotation** | A price offer sent to a customer. |
| **Retention Rate** | Share of last year's customers who bought again this year. |
| **ROI** | Return On Investment: revenue ÷ spend. |
| **Stars** | High-volume, high-profit products. |
| **Stock-Out Risk** | Stock below the company's minimum days-of-inventory. |
| **Strategic** | Low-volume, high-profit products. |
| **Win Rate** | Won quotations as a share of decided quotations. |
| **Working Days** | Calendar days minus weekly rest days (Fridays) and official holidays. |
